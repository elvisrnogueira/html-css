<-- O iframe ainda pode ser usado? -->

1- O que significa iframe: inline frame - quadro em linha
2- Declaramos o iframe com a tag <iframe>
3- Ex: <iframe src="https://cursoemvideo.com.br" frameborder="0"></iframe>
4- Ele faz com que carregue o site inteiro que estiver no src dentro de um unico quadro
5- O frameborder é usado para dizer se queremos borda ou não no iframe - valor padrão é 0 - 0 = não, 1 = sim
6- Alguns sites tem uma proteção para que seus conteúdos não sejam exibidos com o uso de iframe

<-- Configurando iframes -->

1- Caso o iframe não seja compativel com seu navegador podemos deixar uma mensagem no lugar ou um link para que o usuario
acesse o site
2- Ex:
    2.1- <iframe src="https://cursoemvideo.com.br" frameborder="0"> <a href="https://cursoemvideo.com.br">Curso em Video </a></iframe>
    2.2- <iframe src="https://cursoemvideo.com.br" frameborder="0"> [Seu navegador não é compativel] </iframe>
3- O iframe tem o tamanho padrão de 300x150 px
4- Para modificar o tamanho dos iframes podemos declarar o height e width dentro do iframe, ou podemos usar as CSS (as CSS são soberanas)
5- Dentro do iframe existe o parâmetro chamado "scolling" - nele podemos escolher se nosso iframe terá barra de rolagem ou não
6- Seus valores podem ser: auto - para o navegador decidir, yes - para ter a barra de rolagem, no - para não ter a barra de rolagem

<-- Conteúdo local no iframe -->

1- Podemos usar o iframe para importar uma pagina local para seu site
2- Ex: <iframe src="pag001.html" frameborder="0"></iframe>

<-- Navegação no iframe --> 

1- Podemos fazer com que ao clicar em um link abra a página dentro do iframe
2- Para isso declaramos um name ao iframe e no link colocamos o valor do target com o name
3- Ex:
    3.1- <iframe id="tela" name="frame" src="">
    3.2- <a href="paginas-extras/pag001.html" target="frame">Primeira página</a>
