<-- O iframe ainda pode ser usado? -->

1- O que significa iframe: inline frame - quadro em linha
2- Declaramos o iframe com a tag <iframe>
3- Ex: <iframe src="https://cursoemvideo.com.br" frameborder="0"></iframe>
4- Ele faz com que carregue o site inteiro que estiver no src dentro de um unico quadro
5- O frameborder é usado para dizer se queremos borda ou não no iframe - valor padrão é 0 - 0 = não, 1 = sim
6- Alguns sites tem uma proteção para que seus conteúdos não sejam exibidos com o uso de iframe

<-- Configurando iframes -->

1- Caso o iframe não seja compativel com seu navegador podemos deixar uma mensagem no lugar ou um link para que o usuario
acesse o site
2- Ex:
    2.1- <iframe src="https://cursoemvideo.com.br" frameborder="0"> <a href="https://cursoemvideo.com.br">Curso em Video </a></iframe>
    2.2- <iframe src="https://cursoemvideo.com.br" frameborder="0"> [Seu navegador não é compativel] </iframe>
3- O iframe tem o tamanho padrão de 300x150 px
4- Para modificar o tamanho dos iframes podemos declarar o height e width dentro do iframe, ou podemos usar as CSS (as CSS são soberanas)
5- Dentro do iframe existe o parâmetro chamado "scolling" - nele podemos escolher se nosso iframe terá barra de rolagem ou não
6- Seus valores podem ser: auto - para o navegador decidir, yes - para ter a barra de rolagem, no - para não ter a barra de rolagem

<-- Conteúdo local no iframe -->

1- Podemos usar o iframe para importar uma pagina local para seu site
2- Ex: <iframe src="pag001.html" frameborder="0"></iframe>

<-- Navegação no iframe --> 

1- Podemos fazer com que ao clicar em um link abra a página dentro do iframe
2- Para isso declaramos um name ao iframe e no link colocamos o valor do target com o name
3- Ex:
    3.1- <iframe id="tela" name="frame" src="">
    3.2- <a href="paginas-extras/pag001.html" target="frame">Primeira página</a>

<-- Conteúdo no iframe por código -->

1- Dentro do iframe podemos trocar o src por srcdoc que permite com que possamos usar elementos de HTML
2- Ex:

    </iframe>

<-- Incovenientes do iframe -->

1- Não confunda frame com iframe, são coisas diferentes
2- O Google bot apresenta dificuldades para indexar conteúdos que estão em iframe
3- Leitores de telas para pessoas com dificuldades visuais apresentam dificuldades para reconhecer conteúdos que estão em iframe
4- Cuidado com a segurança pois você está abrindo a porta para outro site que você não tem controle - seu site fica exposto para ataques

<-- Tornando iframes mais seguros -->

1- Para bloquar ações potencialmente maliciosas dos sites que você coloca no iframe você deve declarar o atributo sandbox="sandbox" dentro do seu iframe
2- Ex: <iframe src="paginas-extras/pag004.html" sandbox="sandbox">
        Seu navegador não é compativel com isso...
        </iframe>
3- Para impedir com que o conteúdo carregado dentro do iframe colete algum dado do seu site devemos declarar o atributo referrerpolicy="no-referrer" dentro do seu irame
4- Ex: <iframe src="paginas-extras/pag004.html" sandbox="sandbox" referrerpolicy="no-referrer">
        Seu navegador não é compativel com isso...
        </iframe>
5- Para poder permitir alguns acessos do iframe podemos colocar outros valores no sandbox
    5.1- Ex: allow-same-origin = para permitir coisas da mesma origem (pasta/ arquivo)
             allow-forms = para permitir formulários
             allow-scripts = para permitir scripts
    5.2- Ao usar algum desses valores os outros estaram protegidos

<-- Dicas do projeto-social -->

1- border-sizing: border-box; -> faz com que a borda faça parte da caixa do elemento que foi declarado
2- Para ter uma animação mais suave, devemos declarar transition: (valor1 valor2) - valor1: atributo que quer a transição, valor2: tempo
3- Ex: transition: transform .5s; -> o atributo transform vai demorar meio segundo para aparecer/ ser executado

<-- Como criar formulários com HTML5 -->

1- Todo conteúdo do formulário deve estar coberto pela tag <form> </form>
2- Para criar uma caixa de texto onde o usuario pode digitar usamos a tag <input> com o type="text"
    2.1- O type="text" deve estar acompanhado de um name e um id
3- Para criar um botão de enviar, usamos a tag <input> com o type="submit"
    3.1- Para colocar um texto dentro do submit usamos a declaração value="(ESCRITA DO BOTÃO)"

<-- Usar Label vai melhorar seus formulários -->

1- Para remover o a caixa de autocomplete, na tag form, declaramos o atributo autocomplete="value" - tendo o valor de off para desligar e on para ligar o autocomplete
2- Para o botão de submit ter alguma ação nós declaramos na tag form o atributo action="value" - tendo o valor o arquivo da linguagem de programação escolhida
3- Equanto o name é mais utilizado para PHP e HTML5, o id é mais utilizado JS e para uso do label
4- O label serve como rótulo ou texto descritivo para um campo de entrada de dados, para referenciar um campo de entrada com label, declaramos label com o atributo for="value" - tendo o valor como o id passado no input

<-- Métodos GET e POST para formulários -->

1- Existem 2 métodos para envio simples de formulário
2- O método padrão é o GET que é o método que mostra os dados na URL
3- O outro método é o POST esse método não mostra os dado na URL, porém, ao inspecionar a página e ir em Network e Headers, os dados enviados estaram lá
4- Quando você envia dados por GET você só pode enviar 3000bytes - aproximadamente 3000 letras
5- Usamos GET quando o objetivo é buscar ou recuperar dados do servidor (como em uma barra de pesquisa ou filtro), pois ele salva os parâmetros na URL
6- Usamos POST quando é para enviar ou processar dados que alteram o estado do servidor (como cadastros, logins ou arquivos), já que oculta as informações no corpo da requisição (mais usado para dados sensíveis)
7- Se estivermos trabalhando com senhas ou dados muito sensíveis, o ideal é usar o método HTTPS para proteger seus dados
8- Para alterar o método de envio do nosso form nós declaramos o atributo method="value" no form - sendo o valor GET ou POST

<-- Criando caixas de texto e de senhas -->

1- Para criar uma caixa de senha você deve criar um input com type="password"
2- Para criar um botão de limpar/resetar você deve criar um input com type="reset"
3- Para fazer com que o campo sejá obrigatório dentro do input você deve colocar o atributo required
4- Para limitar a quantidade de caractéres de um campo podemos usar (minlenght) para quantidade minima e (maxlenght) para quantidade máxima
5- Para que a caixa mostre na tela um número máximo de caractéres podemos usar o atributo size com o valor de caractéres de preferencia - Ex: size="10" - vai mostrar 10 caractéres
6- Para deixar uma mensagem dentro da caixa usamos o atributo placeholder="value" - sendo o valor a mensagem de preferencia
8- Para fazer seu navegador sugerir o autocomplete de acordo com o que está sendo pedido, podemos usar o atributo autocomplete="value" dentro do input - sendo valor dependendo de qual campo está sendo preechido
    8.1- Lembre-se para usar o autocomplete no input, o autocomplete deve estár com o valor "on" no form

<-- Elementos number, month, date e time em formulários HTML -->

1- Para criar um formulário de texto onde podemos apenas digitar números usamos o type="number" - podemos limitar os números que podemos usar, para valores minimos usamos min e para valores maximos usamos max
2- Para criar um formulário para selecionar o mês, usamos o type="month" - para deixar um valor já pré selecionado, podemos usar o atributo value=""
3- Para criar um formulário para selecionar a data, usamos o type="date"
4- Para criar um formulário para selecionar as horas, usamos o type="time"

<-- Formulários com telefone e e-mail --> 

1- Para criar um formulário de email usamos o type="email" - nele se torna obrigatório ter um @ no campo de texto
2- Para criar um formulário de telefone usamos o type="tel" - você consegue definir um padrão com expressões regulares usando pattern="value"
3- O RegEx sempre irá se iniciar com "^" e terminar com "$" - Ex: pattern="^[0-9]{4}-[0-9]{4}$" - Nesse exemplo só irá aceitar dígitos de 0 a 9 e somente 4 dígitos "-" 4 dígitos
4- Ex de cel: pattern="^\d{4,5}-\d{4}$" - Nesse exemplo - Nesse exemplo só irá aceitar de 4 a 5 dígitos "-" 4 dígitos
5- Ex com DDD: pattern="^\(\d{2}\)\d{4,5}-\d{4}" - Nesse exemplo se abre e fecha parênteses assim = \(\)
6- Podemos agrupar todos os campos semelhantes com a tag <fieldset> e colocar uma legenda com a tag <legend>

<-- Checkbox e Radio button em HTML -->

1- Para criar um formulário de dar check em varias opções usamos o type="checkbox" - Lembre-se de colocar um name e um id com label referenciando
2- Para criar umm formulário de selecionar apenas uma unica opção usamos o type="radio" - Lembre-se de colocar um name e um id com label referenciando
3- O name das opções do radio devem ser o mesmo para que possamos selecionar apenas uma opção
4- Coloque um value para que o para podermos enviar um valor para o back-end
5- O atributo checked faz com que a opçãao atribuida já esteja marcada ao iniciar o sistema

<-- Elementos color, range e file em HTML -->

1- Para criar um formulário para escolher uma cor usamos o type="color"
2- Para criar um formulário para escolher uma "parâmetro" (como escolher o volume) usamos o type="range"
3- Para criar um formulário para enviar um arquivo usamos o type="file"

<-- Select, datalist e textarea em HTML -->

1- Para criar uma lista suspensa (menu de opções) usamos a tag <select> - Lembre-se de colocar um name para enviar o valor ao back-end
2- As opções da lista são criadas com a tag <option> dentro do <select>
3- O atributo value da <option> é o valor que será enviado para o back-end, enquanto o texto entre as tags é o que o usuário visualiza
4- Podemos usar o atributo selected na <option> para deixá-la selecionada por padrão ao carregar a página
5- É recomendado colocar uma primeira opção como "Selecione uma opção" com value="(vazio)" para obrigar o usuário a escolher uma opção válida
6- Podemos agrupar opções utilizando a tag <optgroup>, facilitando a organização de listas maiores
7- Para criar um campo de texto com sugestões de preenchimento usamos a tag <datalist> junto com um <input>
8- O atributo list do <input> deve receber o mesmo id da <datalist> para que as sugestões apareçam
9- As sugestões são criadas utilizando a tag <option> dentro da <datalist>
10- O atributo value da <option> representa o texto que será inserido no campo quando a opção for escolhida
11- Diferente do <select>, o usuário pode digitar qualquer valor, não sendo obrigado a escolher uma das sugestões da <datalist>
12- A <datalist> é indicada para campos de pesquisa ou preenchimento com sugestões, enquanto o <select> é usado quando o usuário deve escolher uma opção da lista
13- Para criar um campo de texto com várias linhas usamos a tag <textarea> - Lembre-se de colocar um name e um id com o label referenciando
14- O atributo name define o nome do dado que será enviado para o back-end
15- O atributo rows define a quantidade de linhas visíveis do campo e o atributo cols define sua largura em caracteres
16- O texto colocado entre a abertura e o fechamento da tag <textarea> será exibido como conteúdo inicial do campo
17- Podemos utilizar o atributo placeholder para exibir uma mensagem de orientação antes do usuário digitar
18- O atributo required torna o preenchimento obrigatório antes do envio do formulário

<-- Elemento output em formulários HTML -->

1- Para exibir o resultado de um cálculo ou de uma ação dentro de um formulário usamos a tag <output>
2- A tag <output> apenas exibe informações, não permite que o usuário digite valores
3- O atributo for pode referenciar os ids dos campos que participaram do cálculo ou da operação
4- O atributo name identifica o resultado caso ele precise ser acessado ou enviado por scripts
5- A tag <output> é muito utilizada em conjunto com JavaScript para atualizar valores automaticamente na página

<-- O que são Media Queries em CSS -->

1- Media Queries são utilizadas para aplicar estilos diferentes dependendo do tamanho da tela ou do dispositivo do usuário

<-- Criando um site com versão para impressora -->

1- Usamos o atributo media no link de um CSS para criar arquivos diferentes para meios diferentess (Media Query)
2- media="screen" - é usado para as telas - Ex: <link rel="stylesheet" href="estilos/tela.css" media="screen"/>
3- media="print" - é usado para impressoras - Ex: <link rel="stylesheet" href="estilos/impressora.css" media="print"/>
4- media="all" - é usado para todos os tipos - Ex: <link rel="stylesheet" href="estilos/todas.css" media="all"/>
5- Tanto "screen" quanto "print" são Media Types

<-- Múltiplas Media Features com CSS -->

1- Media Query é igual a Media Type + Media Features
2- O Media Feature deve estar entre parênteses
3- Ex: <link rel="stylesheet" href="estilos/retrato.css" media="screen and (orientation: portrait)"/>
4- Nesse exemplo estamos criando um arquivo CSS para telas com orientação retrato

<-- Reunindo tudo em um único CSS -->

1- Podemos criar a regra @media no css para usar uma Media Query
2- Ex: @media screen and (orientation: portrait) {} - Exemplo mostra uma Media Query para tela com orientação retrato
