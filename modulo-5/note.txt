<-- O que vamos aprender no módulo 5? -->

1- Flexbox = Caixas Flexiveis
2- O flexbox faz com que os filhos do container se adaptem ao tamanho da tela/ janela
3- O flexbox trabalha em uma unica dimensão seja ela horizontal ou vertical
4- Grid Layout diferente do flexbox, ele é multidimensional

<-- Primeiros passos com Flexbox CSS -->

1- O que surgiu com o CSS3 (2017):
    1.1- CSS Flexible Box - Module Level 1
    1.2- CSS Grid Layout - Module Level 1/2
2- Maneiras de posicionamento no CSS2.1 (ainda são usados): 
    2.1- Block Layout
    2.2- Inline Layout
    2.3- Table Layout
    2.4- Positioned Layout
3- Qual é o formato da água? Vai depender do container - É a mesma coisa com Flexbox
4- Flexbox foi feito para resolver problemas pontuais (problemas onde as caixas não estão se encaixando)
5- Flexbox cria um layout flexivel para adaptar o conteudo para você
6- Quem é o pai? - O pai = flex-container, levará o display: flex;
7- Caso você queira que os flex-items se adaptem como a água eles devem estar configurados com flex: auto;

<-- Direções e Eixos Flexbox CSS -->

1- Configurações de flex-direction: 
    1.1- flex-direction: row; (linha/deitado) - Lido da esquerda para direita
    1.2- flex-direction: row-reverse; (linha/deitado) - Lido da direita para esquerda
    1.3- flex-direction: column; (coluna/em pé) - Lido de cima para baixo
    1.3- flex-direction: column-reverse; (coluna/em pé) - Lido de baixo para cima
2- Dependendo da região onde é lido esse site as direções são invertidas
3- Eixos (axis):
    3.1- (main-axis) eixo principal
        3.1.1- (main-start) Ponto inicial
        3.1.2- (main-end) Ponto final
    3.2- (cross-axis) eixo transversal
        3.2.1- (cross-start) Ponto inicial
        3.2.2- (cross-end) Ponto final
    3.3- Quando configurado flex-direction: row;
        3.3.1- (main-axis) - Lido da esquerda para direita - (main-start) esquerda / (main-end) direita
        3.3.2- (cross-axis) - Lido de cima para baixo - (cross-start) cima / (cross-end) baixo
    3.4- Quando configurado flex-direction: row-reverse;
        3.3.1- (main-axis) - Lido da direita para esquerda - (main-start) direita / (main-end) esquerda
        3.3.2- (cross-axis) - Lido de cima para baixo - (cross-start) cima / (cross-end) baixo
    3.5- Quando configurado flex-direction: column;
        3.3.1- (main-axis) - Lido da cima para baixo - (main-start) cima / (main-end) baixo
        3.3.2- (cross-axis) - Lido de esquerda para direita - (cross-start) esqueda / (cross-end) direita
    3.6- Quando configurado flex-direction: column-reverse;
        3.3.1- (main-axis) - Lido da baixo para cima - (main-start) baixo / (main-end) cima
        3.3.2- (cross-axis) - Lido de esquerda para direita - (cross-start) esqueda / (cross-end) direita
