<-- O que vamos aprender no módulo 5? -->

1- Flexbox = Caixas Flexiveis
2- O flexbox faz com que os filhos do container se adaptem ao tamanho da tela/ janela
3- O flexbox trabalha em uma unica dimensão seja ela horizontal ou vertical
4- Grid Layout diferente do flexbox, ele é multidimensional

<-- Primeiros passos com Flexbox CSS -->

1- O que surgiu com o CSS3 (2017):
    1.1- CSS Flexible Box - Module Level 1
    1.2- CSS Grid Layout - Module Level 1/2
2- Maneiras de posicionamento no CSS2.1 (ainda são usados): 
    2.1- Block Layout
    2.2- Inline Layout
    2.3- Table Layout
    2.4- Positioned Layout
3- Qual é o formato da água? Vai depender do container - É a mesma coisa com Flexbox
4- Flexbox foi feito para resolver problemas pontuais (problemas onde as caixas não estão se encaixando)
5- Flexbox cria um layout flexivel para adaptar o conteudo para você
6- Quem é o pai? - O pai = flex-container, levará o display: flex;
7- Caso você queira que os flex-items se adaptem como a água eles devem estar configurados com flex: auto;

<-- Direções e Eixos Flexbox CSS -->

1- Configurações de flex-direction: 
    1.1- flex-direction: row; (linha/deitado) - Lido da esquerda para direita
    1.2- flex-direction: row-reverse; (linha/deitado) - Lido da direita para esquerda
    1.3- flex-direction: column; (coluna/em pé) - Lido de cima para baixo
    1.3- flex-direction: column-reverse; (coluna/em pé) - Lido de baixo para cima
2- Dependendo da região onde é lido esse site as direções são invertidas
3- Eixos (axis):
    3.1- (main-axis) eixo principal
        3.1.1- (main-start) Ponto inicial
        3.1.2- (main-end) Ponto final
    3.2- (cross-axis) eixo transversal
        3.2.1- (cross-start) Ponto inicial
        3.2.2- (cross-end) Ponto final
    3.3- Quando configurado flex-direction: row;
        3.3.1- (main-axis) - Lido da esquerda para direita - (main-start) esquerda / (main-end) direita
        3.3.2- (cross-axis) - Lido de cima para baixo - (cross-start) cima / (cross-end) baixo
    3.4- Quando configurado flex-direction: row-reverse;
        3.3.1- (main-axis) - Lido da direita para esquerda - (main-start) direita / (main-end) esquerda
        3.3.2- (cross-axis) - Lido de cima para baixo - (cross-start) cima / (cross-end) baixo
    3.5- Quando configurado flex-direction: column;
        3.3.1- (main-axis) - Lido da cima para baixo - (main-start) cima / (main-end) baixo
        3.3.2- (cross-axis) - Lido de esquerda para direita - (cross-start) esqueda / (cross-end) direita
    3.6- Quando configurado flex-direction: column-reverse;
        3.3.1- (main-axis) - Lido da baixo para cima - (main-start) baixo / (main-end) cima
        3.3.2- (cross-axis) - Lido de esquerda para direita - (cross-start) esqueda / (cross-end) direita

<-- Empacotamento e fluxo no Flexbox CSS -->

1- Wrap significa empacotamento (encapsulamento)
2- O encolhimento dos itens vai depender do conteudo em si
3- Configurações de flex-wrap:
    3.1- flex-wrap: nowrap; (padrão) - quando diminuir do flex-container o tamanho não ira quebrar os conteudos, eles não iram sair da sequencia
    3.2- flex-wrap: wrap; -  quando diminuir do flex-container ira quebrar o conteudo no sentido do (cross-axis)
    3.3- flex-wrap: wrap-reverse; - quando diminuir do flex-container ira quebrar o conteudo no sentido oposto do (cross-axis)
4- flex-flow é uma junção de flex-direction + flex-wrap - shorthand
5- Exemplo de flex-flow:
    5.1- flex-flow: row nowrap; - faz a configuração de flex-direction: row; + flex-wrap: nowrap;
6- Recomendação da W3C - Utilize flex-flow no lugar de flex-direction e flex-wrap

<-- Alinhamento nos eixos Flexbox -->

1- O justify-content ira apenas fazer o alinhamento referente ao (main-axis)
2- Configurações de justify-content:
    2.1- justify-content: flex-start; - O primeiro item irá ficar grudado no main-start
        2.1.1- O espaço em branco sempre irá ficar grudado no main-end
    2.2- justify-content: flex-end; - O último item irá ficar grudado no main-end
        2.2.1- O espaço em branco sempre irá ficar grudado no main-start
    2.3- justify-content: center; - Todos os itens irão ficar centralizados em relação ao (main-axis)
        2.3.1- Os espaços em branco são distribuidos igualmente para o main-start e main-end
    2.4- justify-content: space-between; - Coloca o primeiro item no main-start e o último item no main-end
        2.4.1- Os espaços em branco são distribuidos igualmente entre os itens
    2.5- justify-content: space-evenly; - Cria espaçamentos entre todos os itens sendo antes e depois deles
    2.6- justify-content: space-around; - Pega o container, cria espaços iguais dividos pelo número de itens, e centraliza os itens dentro desse espaço
        2.6.1- Cria um espaço em branco antes do primeiro e depois do último elemento porém entre os elementos cria dois espaçamentos, um que é o final do anterior e outro o inicio do posterior
3- O align-items ira apenas fazer o alinhamento referente ao (cross-axis)
4- Configurações de align-items:
    4.1- align-items: stretch; (padrão) - Estica os itens no sentido do (cross-axis)
    4.2- align-items: flex-start; - Os elementos irão ficar grudado no cross-start
        4.2.1- O espaço em branco sempre irá ficar grudado no cross-end
    4.3- align-items: flex-end; - Os elementos irão ficar grudado no cross-end
        4.3.1-  O espaço em branco sempre irá ficar grudado no cross-start
    4.4- align-items: center; - Todos os elementos irão ficar centralizados em relação ao (cross-axis)
        4.4.1- Os espaços em branco são distribuidos igualmente para o cross-start e cross-end

<-- Centralização absoluta em Flexbox --> 

1- Para centralizar um item de forma absoluta dentro de um container, devemos declarar duas propriedades:
    1.1- justify-content: center;
    1.2- align-items: center;

<-- Alinhamento de elementos empacotados no Flexbox -->

1- justify-content alinha o conteudo dentro do eixo principal
2- align-items alinha o conteudo dentro do eixo transversal
3- align-content alinha o conteudo dentro do eixo transversal mas quando estão empacotados
4- Configurações de align-content:
    4.1- align-content: stretch; (padrão) - As linhas são esticadas para ocupar todo o espaço disponível no (cross-axis)
    4.2- align-content: flex-start; - Gruda todos os itens no cross-start e deixa o espaço em branco no cross-end
    4.3- align-content: flex-end; - Gruda todos os itens no cross-end e deixa o espaço em branco no cross-start
    4.4- align-content: center; - Todas as linhas ficam centralizadas em relação ao (cross-axis)
        4.4.1- O espaço em branco é dividido igualmente entre o cross-start e o cross-end
    4.5- align-content: space-between; - A primeira linha fica no cross-start e a última linha fica no cross-end
        4.5.1- O espaço restante é distribuído igualmente entre as linhas
    4.6- align-content: space-evenly; - Todo o espaço disponível é dividido igualmente
        4.6.1- A distância entre todas as linhas e as bordas do container é exatamente a mesma
    4.7- align-content: space-around; - Pega o container, cria espaços iguais dividos pelo número de linhas, e centraliza os itens dentro desse espaço

<-- Anatomia dos itens Flexbox -->

1- Todo item em flexbox vai ter order: 0; por padrão
2- A propriedade order faz com que o item flexivel altere sua posição de acordo com a ordem numerica colocada (do menor pro maior)
3- A propriedade align-self se aplica aos itens e funciona diretamente ao (cross-axis)
4- Configurações de align-self:
    4.1- align-self: auto; - Herda a caracteristica de alinhamento vertical do seu pai
    4.2- align-self: flex-start; - Alinhamento grudado no cross-start
    4.2- align-self: flex-end; - Alinhamento grudado no cross-end
    4.2- align-self: center; - Calcula o meio entre o cross-start e o cross-end
    4.2- align-self: stretch; - Estica o item fazendo com que ele ocupe o cross-axis inteiro

<-- Propriedade flex-basis em Flexbox -->

1- Configurações de flex-basis:
    1.1- flex-basis: auto; (padrão) - O tamanho do elemento dentro do (main-axis) é ditada atraves do tamanho do conteudo
    1.2- flex-basis: 200px; (tamanho) - Cria os elementos com o tamanho colocado enquanto der
2- Podemos declarar o flex-basis com diferentes tamanhos entre os elementos
